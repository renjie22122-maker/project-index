# Project index

Selected projects and curated coursework implementations. Data, model weights, credentials and generated outputs are excluded. Full course archives, research references and thesis drafts remain private.

## Public coursework portfolios

| Repository | Contents |
|---|---|
| [image-processing-projects](https://github.com/renjie22122-maker/image-processing-projects) | Image morphing and Poisson image editing implementations. |
| [geometry-processing-projects](https://github.com/renjie22122-maker/geometry-processing-projects) | Halfedge mesh operations, curvature, spectral analysis and smoothing. |
| [inverse-imaging-projects](https://github.com/renjie22122-maker/inverse-imaging-projects) | Regularised deconvolution, tomography and denoising implementations. |
| [visual-computing-algorithms](https://github.com/renjie22122-maker/visual-computing-algorithms) | Selected student-implemented regression, filtering and neural components. |
| [computer-graphics-projects](https://github.com/renjie22122-maker/computer-graphics-projects) | Ray tracing and path tracing implementations for the UCLCG renderer. |
| [machine-vision-projects](https://github.com/renjie22122-maker/machine-vision-projects) | Corner tracking, homography, planar pose and pose-sequence regression implementations. |

Each portfolio documents its scope, dependencies and validation limits. These are curated selections rather than complete course archives.
